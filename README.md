# 대구 학사일정 찾기

2026학년도 대구 초·중·고 학사일정과 정기시험, 학교 부교재를 학교 이름으로 찾는 페이지.

- 주소 하나로 누구나 열람
- 즐겨찾기 (각자 브라우저에 저장)
- A4 가로 표로 인쇄 · 엑셀 내려받기 · 인쇄물에 학원 이름 넣기

## 자료 출처

- 학사일정 — 대구광역시교육청 「2026학년도 학사일정 현황」
- 부교재 — 학원 자체 조사분 (출처가 다릅니다)

## 구성

`index.html` 한 장이 전부입니다. 서버도 데이터베이스도 없습니다.
자료가 파일 안에 들어 있어 접속하면 바로 뜨고, 검색은 브라우저에서 처리합니다.

## 갱신

교육청이 새 파일을 내면 `index.html` 을 새로 만들어 갈아 끼웁니다.

## 2단계 (예정)

선생님들이 바뀐 시험일·부교재를 제안하고, 승인된 것만 반영되는 기능.
`/api/suggest` 가 살아 있으면 제안 버튼이 저절로 나타납니다. 없으면 숨습니다.
